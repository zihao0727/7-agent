# 依据卷号下载档案文件 Skill

## 概述

本 Skill 提供根据**卷号（jh）** 下载对应档案压缩包的能力。用户在对话中可以请求下载特定卷号的档案，系统将调用后端 API 生成预签名下载链接（presigned URL），并将该链接返回给前端。前端会检测到该链接并在新标签打开或触发下载。

---

## 功能说明

### 工具：`archive_download`

**描述**: 根据卷号（jh，例如 `WYGZC2025Z183`）生成并返回一个可供前端直接下载的预签名 URL（`presigned_url`）。

**参数**:
- `jh` (string, 必选): 卷号，格式示例 `WYGZC2025Z183`

**返回值**:
- 成功时返回包含 `presigned_url` 的消息，例如：
```
下载成功！
presigned_url: https://...（预签名下载链接）
文件名: WYGZC2025Z183_archive_message.zip
```
- 失败时返回错误信息（如卷号不存在、服务器错误等）

**使用示例**:
```
用户: 帮我下载卷号 WYGZC2025Z183 的档案
AI: [调用 archive_download 工具，参数 jh=WYGZC2025Z183]
→ 返回: 下载成功！ presigned_url: https://... 文件名: WYGZC2025Z183_archive_message.zip
前端: 识别 presigned_url 并在新标签打开或触发下载
```

---

## 错误处理

| 错误类型 | 描述 | 原因 |
| :--- | :--- | :--- |
| 卷号不存在 (404) | "找不到卷号 '...' 对应的档案记录" | 该卷号在系统中不存在 |
| 参数错误 (422) | "卷号（jh）不能为空" | 卷号为空或格式不合法 |
| 服务器错误 (500) | "服务器内部错误：打包下载失败" | API 服务异常 |
| 网络错误 | "网络错误：..." | 网络连接失败或超时 |

---

## 前端集成

### 自动下载方式（推荐）

当 AI 返回包含 `presigned_url` 或可直接下载的 URL 时，前端会自动检测并处理：

1. 检测消息中是否包含 `presigned_url:` 或者裸的 `https://...` 链接
2. 若检测到 URL，前端会尝试使用 `a.href = url; a.download = filename; a.click()` 触发下载；若跨域或被浏览器策略阻止，则在新标签页打开该 URL
3. 若需要额外的认证或头部，前端应调用后端代理以便安全下载（视场景而定）

### 手动下载方式

用户仍会在消息中看到一个“下载”按钮，点击即可在前端执行以上下载逻辑。

---

## 技术细节

- **API 端点**: `https://zzh.wygzc.cn/v3/api/app20/archive-message/download`
- **请求方法**: GET
- **查询参数**: `jh=<卷号>`
- **响应类型**: 
  - 成功: JSON，例如 `{ "presigned_url": "https://..." }` 或直接返回一段包含 `presigned_url` 的文本
  - 失败: JSON 错误信息
- **文件命名**: `{jh}_archive_message.zip`（如果后端未返回文件名，前端会从 URL 中尝试推断）
