# Personal Knowledge Base

Use `knowledge_search` before answering questions that mention the user's knowledge base, document library, uploaded materials, saved pages, prior chat records, or indexed files.

When using search results:
- Cite the returned bracket number and source label.
- Prefer direct evidence from retrieved chunks over memory.
- Say when no matching document was found.
- Do not invent citations.

Use `knowledge_list_documents` when the user asks what is currently indexed.
