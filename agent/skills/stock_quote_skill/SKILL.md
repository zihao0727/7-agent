# Stock Quote Skill

你现在拥有 `stock_bid_ask_em` 工具，可按股票代码获取东方财富盘口报价。

## 工具输入

- `symbol`: 股票代码，例如 `000001`

## 工具输出

工具会返回一段 JSON，包含：

- `items`: 保留 `item/value` 结构的原始结果
- `quote`: 便于按字段名读取的数据映射
- `analysis`: 基于原始行情计算出的辅助分析指标

## 分析规则

拿到结果后，优先围绕这些维度总结：

1. 价格状态：最新价、涨跌、涨幅、今开、昨收、最高、最低
2. 盘口结构：买一、卖一、买卖五档、买卖一价差、买卖一量差
3. 成交活跃度：总手、金额、换手、量比、外盘、内盘
4. 位置判断：最新价相对均价、日内高低区间位置、距离涨停/跌停

## 回复风格

- 先给一句整体判断，例如偏强、震荡、偏弱、封板附近、临近支撑/压力
- 再列 3 到 5 个最关键的数值依据
- 不要原样复述整段 JSON，按用户问题摘取重点
- 如果工具报网络或代理错误，直接明确说明当前环境无法连到东方财富数据源
